## Project Overview

Chez is a chess engine written in Zig featuring a TUI for human-vs-AI gameplay. It uses magic bitboards for move generation and negamax search with alpha-beta pruning for AI decision-making.

## Build Commands

```bash
zig build              # Build both executables (outputs to zig-out/bin/)
zig build test         # Run all tests
./zig-out/bin/tui      # Run the chess TUI
./zig-out/bin/precompute  # Regenerate magic bitboard tables (rarely needed)
```

## Architecture

### Core Data Flow
1. **State.zig** holds the board position using bitboards (6 for piece types, 2 for colors)
2. **movegen.zig** generates legal moves using magic bitboard lookups from **moves.zig**
3. **search.zig** uses negamax with alpha-beta pruning, backed by a transposition table
4. **evaluation.zig** scores positions using material, piece-square tables, pawn structure, and mobility

### Key Modules

- **Bitboard.zig**: Core bit manipulation (64-bit integers representing the 8x8 board). Immutable operations return new values; mutating variants use `Assign` suffix.
- **game.zig**: Type definitions (Square=u6, Piece=u3, Color=u1, Move, CastlingRights) and utilities
- **magics.zig** + **moves.zig**: Pre-computed magic bitboard constants and move lookup tables (auto-generated by precompute.zig)
- **main.zig**: TUI game loop - handles FEN input, move parsing, board rendering

### Conventions

- Pieces: pawn=0, knight=1, bishop=2, rook=3, queen=4, king=5
- Colors: white=0, black=1 (toggle with `~`)
- Squares: 0-63 (a1=0 to h8=63), row-major
- Evaluation scores are always from the current player's perspective
